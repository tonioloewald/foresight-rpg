Image

visual illusion (formerly Images)

A Fundamental — a Field of Magical Knowledge whose applications reach 50m and last 10min; the usual props are mirror, lens, or mask. Learn it Basic (1 yr) for the easy end, Advanced (3 yr) for the deep.

Clarification: "remove" image actually means to replace an image with what the invoker (controller) believes would be seen were that image not present (ie. not the same as making the object transparent, with the refractive index of air). So a character could not, for example, see through a door by "removing" its image. The invoker might put a sandestin with eyesight and remove image into the door, and then see through it…
