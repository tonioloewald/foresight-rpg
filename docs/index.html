ForeSight RPG

A streamlined, modern edition of the ForeSight tabletop RPG, built on the unpublished 2004 second edition and the 1986 original.

One rule: Success Chance = Score × Ease Factor — roll D100 under it. Everything else is that rule applied to different situations.

Use the navigation to browse the rules one-pagers, or open the live Character Builder.

This is work-in-progress

If you have a problem with these rules file an issue. But remember, the goal of ForeSight is to be "all the rules you can remember", so producing big lists of stuff or complex definitive procedures for things (like Aftermath's bullet impact resolution flowchart, or Universe's wilderness encounter system, or even RuneQuest 3's Dropped Oil Lamp Table) is not the point.

You, the GM or player, have better insight into the weird special case at hand than I or any game designer can ever possibly have. Use the one rule and get on with the game.

Colophon

This site, the "app" you're using, the system that turns it into a printable page or an ePub, was all created using the tosijs documentation system which itself is one of the end results of a forty-year career building software that was started because I wanted to publish these rules.
