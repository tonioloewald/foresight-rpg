Link

Intensity
1
Code
§11B3
Source
extension

Increase the duration of any non-immediate magical effect of which this application is a part indefinitely, by paying a continuing fatigue cost for the effect. The invoker must pay fatigue equal to the energy of the effect (were this application not a part of it) at intervals equal to the effect's normal duration (ie. the duration of the effect without this application). The effect is then treated as controlled, whether or not it would otherwise be controlled, insofar as the invoker must concentrate on the effect he/she is sustaining or it will dissipate as though its time had elapsed (similarly the invoker may end the effect at any time); this does not prevent the invoker from controlling those aspects of the effect which would normally be controlled otherwise. The invoker begins paying fatigue when the effect's duration would normally expire. A character maintaining an effect in the above manner cannot regain fatigue by resting.

Matrix Creation

Intensity
4
Code
§11A8
Source
extension

Create a "matrix" for any effect of which this application is a part, in some chosen object within range. The matrix may be used by a character to invoke the effect (without this application) by performing the number of incant actions which would normally be required to invoke it (ie. its energy were this application not a part of it) while holding (and pointing, or whatever) the object containing the matrix. The use of any matrix, even one made by a sorceror, requires the presence of the props associated with its component applications. Non-consumed props may be incorporated into the matrix; consumed props will have to be supplied by the user. After performing the requisite number of incant actions, the matrix user makes an Incant roll as though invoking the effect him/herself (even a non-magician may do this): - QR1-4 — successful invocation. - QR7 — successful invocation (although the effect will be very easy to resist), and a D20 backfire. - QR10 — a D100 backfire, and the destruction of the matrix. Optional (even if Casting is in use): Casting can be used instead of Incantation, as above, by performing a single Cast action. Note: after attempting (successfully or otherwise) the invocation of an effect including this application, the magician will be extremely fatigued, suffering a -1 modifier to all activity; to recover, he/she must pay 50 EPs, and rest for at least one week, without interruption.
