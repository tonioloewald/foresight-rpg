Divination

knowledge of the hidden, distant, or yet to come

A Fundamental — a Field of Magical Knowledge whose applications reach varies and last immediate; the usual props are utilised.. Learn it Basic (1 yr) for the easy end, Advanced (3 yr) for the deep.

Ask

Intensity
5
Code
§7A13
Source
divination

Gain a single-word reply (you can call it an answer if you're optimistic) to a question of the invoker's choice. If the answer cannot be expressed in one word, or if the question is poorly defined (eg. if the GM can't understand it, or doesn't want to answer it), then no reply is forthcoming. (Range: infinite.)* !!!

Question

Intensity
6
Code
§7A14
Source
divination

Gain a single-clause reply to a question of the invoker's choice. Otherwise as per Ask (§7A13). !!! The ramifications of these two applications are fairly broad, and a wise GM may wish to nobble them (see the note concerning applications marked '!!!'), or be extremely ornery in determining what constitutes a well-defined question. Recommended reading for this includes H.W. Fowler's Modern English Usage.
